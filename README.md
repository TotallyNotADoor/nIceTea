## nIceTea
A crude, feature-poor game framework badly written in C++ with [Raylib](https://github.com/raysan5/raylib)   

Features:   
1.  Easier rendering
    * Classes like AnimatedSprite, which only needs an atlas, a set of positions (frames), animation speed and calling UpdateAnimation every frame
2. Built-in AABB collision "physics" code (stops the object when it hits a collider)
